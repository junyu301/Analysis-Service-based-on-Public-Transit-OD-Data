# 基于大数据的公共交通 OD 分析服务

## 📖 项目简介
本项目为 **2024“和利时杯”第十一届浙江省大学生服务外包创新应用大赛** 参赛作品（项目编号：1001）。随着城市规模扩大，公共交通系统趋于复杂，本项目旨在开发一个智能交通分析平台，通过深度的 OD（Origin-Destination，即起终点）数据挖掘与分析，解决公共交通资源调度优化、拥堵成因分析和乘客出行需求洞悉等痛点问题。

## 🎯 目标受众
本平台主要面向以下客户群体，提供多维度的分析、优化和营销服务：
* **公共交通管理部门与规划部门**
* **公共交通运营商与投资商**

## 🚀 核心功能
* **智能排班**：实现运力需求精准匹配，针对司机数量、工时、排班效率、准点率、调度次数等进行多目标优化。
* **线网优化**：基于区域全局、全方式的 OD 数据分析，挖掘潜在乘客需求，为交通线网的优化提供精准决策和多套优化方案。
* **城市交通管理**：实现区域交通实时监控，提供 OD 调查、宏观需求分析、出行方式测算以及拥堵成因分析与判断。
* **MaaS 优化**：针对景区、园区、交通枢纽等运力需求波动大、空间复杂的痛点场景，提供灵活的运力匹配与 MaaS（多模式出行即服务）效率优化。
* **线下商业化**：洞悉乘客出行规律，为线下商业化服务（如活动策划、品牌宣传）提供精准匹配，分析商业价值，助力政府招商引资。

## 🛠️ 技术架构与技术栈
项目采用分层架构设计，包含数据源层、数据集成层、数据算法层、数据服务层及业务应用层：
* **前端框架**：Vue3
* **后端与网关**：Java, Spring Boot, Gateway
* **数据库与大数据组件**：PostgreSQL, Hadoop, Spark
* **核心算法引擎**：Dijkstra, Prophet, 大规模并行计算及机器学习/深度学习框架（如 TensorFlow, PyTorch）

## 🧩 典型应用系统集成
底层提供 9 种基础应用（如路径流量溯源、可达性分析、路口冲突行为分析等）。通过模块的灵活组合，平台构建了四大高度集成的业务系统：
1. **公交大数据辅助决策系统**
2. **轨道 TOD 大数据辅助决策系统**
3. **人口辅助决策系统**
4. **停车辅助决策系统**
