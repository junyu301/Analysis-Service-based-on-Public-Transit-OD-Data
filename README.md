# Analysis-Service-based-on-Public-Transit-OD-Data


## 📖 项目简介
[cite_start]本项目为 **2024“和利时杯”第十一届浙江省大学生服务外包创新应用大赛** 参赛作品（项目编号：1001）[cite: 81, 82, 85][cite_start]。随着城市规模扩大，公共交通系统趋于复杂，本项目旨在开发一个智能交通分析平台，通过深度的 OD（Origin-Destination，即起终点）数据挖掘与分析，解决公共交通资源调度优化、拥堵成因分析和乘客出行需求洞悉等痛点问题 [cite: 10, 11]。

## 🎯 目标受众
[cite_start]本平台主要面向以下客户群体，提供多维度的分析、优化和营销服务 [cite: 13]：
* [cite_start]**公共交通管理部门与规划部门** [cite: 13]
* [cite_start]**公共交通运营商与投资商** [cite: 13]

## 🚀 核心功能
* [cite_start]**智能排班**：实现运力需求精准匹配，针对司机数量、工时、排班效率、准点率、调度次数等进行多目标优化 [cite: 15, 22]。
* [cite_start]**线网优化**：基于区域全局、全方式的 OD 数据分析，挖掘潜在乘客需求，为交通线网的优化提供精准决策和多套优化方案 [cite: 15, 27]。
* [cite_start]**城市交通管理**：实现区域交通实时监控，提供 OD 调查、宏观需求分析、出行方式测算以及拥堵成因分析与判断 [cite: 15, 30, 31]。
* [cite_start]**MaaS 优化**：针对景区、园区、交通枢纽等运力需求波动大、空间复杂的痛点场景，提供灵活的运力匹配与 MaaS（多模式出行即服务）效率优化 [cite: 15, 36, 37]。
* [cite_start]**线下商业化**：洞悉乘客出行规律，为线下商业化服务（如活动策划、品牌宣传）提供精准匹配，分析商业价值，助力政府招商引资 [cite: 15, 42, 43]。

[cite_start]项目采用分层架构设计，包含数据源层、数据集成层、数据算法层、数据服务层及业务应用层 [cite: 513, 514]：
* [cite_start]**前端框架**：Vue3 [cite: 1201]
* [cite_start]**后端与网关**：Java, Spring Boot, Gateway [cite: 1202, 1203, 1211]
* [cite_start]**数据库与大数据组件**：PostgreSQL, Hadoop, Spark [cite: 316, 1200, 1210]
